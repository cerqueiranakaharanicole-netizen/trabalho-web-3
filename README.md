Atividade MVC Visualizar Entregas
Utilizar a arquitetura MVC para um sistema de biblioteca.
Teremos 2 componente: Usuários, livros.
Será necessário desenvolver uma página inicial, que irá disponibilizar o acesso a página dos usuários e a página dos livros.

Será necessário implementar:
- Get todos os usuários, (pesquisar)
- Get usuário por documento (pesquisar)
- Post usuário (inserir)
- Put usuário (editar)
- Delete usuário

- Get todos os livros (pesquisar)
- Get livro por nome (pesquisar)
- Get livros de um autor (pesquisar)
- Post livros (inserir)
- Put livros (editar)
- Delete livros
